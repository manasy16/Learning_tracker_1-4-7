# LinkedIn Post Draft

I built a small Python desktop app called Learning Tracker 1-4-7.

It helps me log topics I study and reminds me to revise them after 1 day, 4 days, and 7 days.

In this project, I learned:

- How to create a Windows tray icon using `pystray`
- How to build small desktop windows using `pywebview`
- How JavaScript can call Python functions in a desktop app
- How to store local data using SQLite
- How to save app settings and logs properly
- Why background apps need careful handling of threads and UI events

This was a simple but useful project for understanding how Python desktop apps work in the background.
